01

Tool availability

The bundled Claude Code runtime selects task-tool defaults by model. This app explicitly opts in and displays actual initialized tools. Native Task tools and legacy TodoWrite are separate verified experiments.

02

Progress is reported work

A completed task means the agent successfully updated its list. It is not proof that the underlying work is correct. Inspect independently read files, native feedback and application-specific checks.

03

Requests versus confirmed state

The browser receives both requests and results. This tracker commits status changes after successful correlated results, improving on request-only progress displays when tools can fail or be denied.

04

Task IDs and aliases

TaskCreate assigns IDs in tool_use_result.task.id. Raw model input can use taskId, id or task_id and activeForm or active_form. Unknown IDs are not silently synthesized.

05

Legacy list semantics

TodoWrite replaces an entire list. It does not supply TaskCreate IDs. This interface labels its own display keys legacy-row-N; they are explicitly local presentation keys.

06

Lifecycle and costs

TaskCreate, TaskUpdate, TaskList and TaskGet are planning tools, distinct from background-task system notifications. This app launches no subagents or background work. Queries are bounded by turns, a six-minute host timeout and a $0.60 SDK budget threshold, which is not a prepaid cap.

export function validateConfig(value: unknown): RunConfig {
  const c = value as Record<string, unknown>;
  if (!c || typeof c !== "object" || !MODES.includes(c.mode as never))
    throw new Error("Choose a listed todo experiment.");
  if (Object.keys(c).some((k) => k !== "mode"))
    throw new Error("Only the classroom mode can be configured here.");
  return { mode: c.mode as RunConfig["mode"] };

6. Keep requests provisional

Store each task request once by tool-use ID. A request alone does not add a confirmed task or change its status.

Source: src/tracker.ts · lines 18–24 · selected source; surrounding code omitted

request(call: Call) {
    if (!["TaskCreate", "TaskUpdate", "TodoWrite"].includes(call.name)) return;
    if (this.seenCalls.has(call.id)) return;
    this.seenCalls.add(call.id);
    this.calls.set(call.id, structuredClone(call));
    // Requests remain provisional until their correlated result succeeds.
  }
