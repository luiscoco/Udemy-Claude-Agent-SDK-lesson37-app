Install the SDK, configure your key and run the classroom comparisons.

01

Prerequisites

Use Node.js 24+, model API access and credit. Windows may require Git Bash. Python is only needed to regenerate student pages.

node --version
npm --version
02

Install and configure .env

Enter the app folder, install locked dependencies, preserve an existing .env and enter your own model key privately.

cd .\agent-sdk\lesson37-todo-progress
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start and navigate

Keep the terminal open and visit the printed URL. Five navigation buttons link the lab, learning goals, setup, UML diagram and source walkthrough.

npm start
# http://127.0.0.1:3137
04

Watch a real plan and website build

Compare Plan only with Lifecycle. Run Website and watch three tasks progress as actual HTML and CSS files are written. The explicit work hook delay is 1.8 seconds per classroom Read or Write.

npm run sample:env -- plan
npm run sample:env -- lifecycle
npm run sample:env -- website
05

Inspect IDs, labels and deletion

Compare the actual create tool request with its paired result. Run Delete, Rename and Read back; inspect TaskList and TaskGet output. Raw key aliases are supported by the tracker.

npm run sample:env -- delete
npm run sample:env -- rename
npm run sample:env -- readback
06

Compare failure, legacy tools and limits

Denied update must leave confirmed progress pending. Legacy enables TodoWrite with CLAUDE_CODE_ENABLE_TASKS=0 and replaces the entire list. Capped records an actual error_max_turns result and the following exception. Download observations and run offline tests.

npm run sample:env -- denied
npm run sample:env -- legacy
npm run sample:env -- capped
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3137
# Windows only, if needed:
# CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. Choose a todo experiment, watch confirmed lifecycle changes and inspect actual calls, results and files. Change PORT if 3137 is occupied. The classroom Read and Write hooks deliberately pause for 1.8 seconds.
